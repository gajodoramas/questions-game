# Questions Game

![Kotlin](https://img.shields.io/badge/Kotlin-1.7.10-7F52FF?logo=kotlin&logoColor=white)

**Questions Game** is a `true` or `false` questions app. It has timer, difficulty,
statistics, random questions, possibility to add new questions and local
persistence.

The project was built using **Kotlin** in **Android Studio**.

> [!NOTE]
> Developed as a student project (2021 - 2023) under time constraints,
> this application provides core functionality but remains a prototype.
> Please be aware that you may encounter bugs or non-production-ready code.
